# Reactor re-route device (design notes, Oct 26 2026)

Reference: Brad's photo of a rugged military display (black chassis, side connectors on the left, column of about eight buttons on the right, bottom row of eight square keys, map screen with a small inset picture).

## Layout (proposed)
- Screen: puzzle area. Inset picture: live reactor core and gate feed that flickers when unstable.
- Right column: D-pad, select, mode, brightness.
- Bottom row: number keys 1 to 5 plus three rotary knobs.

## Puzzles chosen by Brad
- Conduit Sudoku (existing 4 by 4, values 1 to 5): power events.
- Three-knob balance (Gate, Lab, Shields): easy, relay installs. Knobs nudge each other slightly.
- Rotating extras: pipe routing, breaker sequence, phase match, load shedding.
- Brad wants some of these mixed together (multi-stage events).

## Fixed pairs (approved Oct 26 2026)
| Event | Stage 1 | Stage 2 |
|---|---|---|
| Power fluctuation (every 11 to 15 activations) | Conduit Sudoku | Breaker sequence, restoring power in order |
| Reactor tier I install | Three-knob balance | Load shedding |
| Reactor tier II install | Pipe routing | Breaker sequence |
| Reactor tier III install | Three-knob balance | Phase match |
| ZPM install | Pipe routing | Phase match |
- Abandoning a power event works as it does now. Closing the device mid-puzzle parks it with no penalty and finished stages stay finished.
