MISSION PANEL // LAYOUT MOCKUPS

Each frame is drawn at the real size of the Gate Room's Mission panel (about 616 × 236). They're clickable: add and remove items, change mission type. Test destination is P3X-4471, medium hazard, Level 2. Numbers are placeholders.

A // ASSET BOARD

Three columns: mission type down the left, everything on station shown as chips in the middle, and the manifest with live odds on the right.

  • No dropdowns. You see all available teams, vehicles and MALPs at once; ineligible ones are greyed out for the selected type.
  • The manifest shows ambush chance, yield, power cost and ETA before you send.
  • Gets busy once you have 8+ teams. The chip pool scrolls.

B // LOADOUT SLOTS

Destination strip on top, mission type bar, then six fixed slots, like gear slots on a squad card. Click an empty slot to pick what fills it. A summary bar with SEND runs along the bottom.

  • Cleanest look, and closest to the Armory loadout style already in the game.
  • Slot rules come from the type: Assault opens more team slots, Recon Survey only one.
  • One extra click per item (open slot, then pick).

C // BRIEFING STEPS

A three-step flow: 1 TYPE, 2 ASSETS, 3 REVIEW. Each step fills the panel: type cards with a one-line rule, an asset checklist with stats per row, then a review table with the odds and SEND.

  • Most room per step, and the easiest to learn. Rules text lives on the type cards instead of a loose help line.
  • Slowest for repeat missions. Could remember the last setup so repeats are TYPE → SEND.
